# Lil Robb's Girlfriend — accessible companion robot project

**Status:** Revision G design and engineering research only. No robot is assembled, safety-validated or connected to a working GPT service.

**Public showcase (once GitHub Pages is enabled):** https://matthagersenior.github.io/lilrobbsgirlfriend/

## What this repository contains

- [Current design decision](docs/CURRENT_BUILD_DECISION.md)
- [Revision G mechanical design](docs/REV_G_MECHANICAL_DESIGN.md)
- [Revision G conversational architecture](docs/REV_G_CHATGPT_COMPANION_ARCHITECTURE.md)
- [Parametric Revision G OpenSCAD model](cad/robot_revG.scad)
- [Revision F assembly research](docs/REV_F_EASY_ASSEMBLY.md)

The project explores an affordable, compact, friendly rover designed for accessible one-handed use, possible phone controls, online GPT-based conversation, and modular printed mechanics. **Every operating feature is a design goal rather than an implemented claim.**

## Public website

The mobile-friendly, self-contained landing page is [index.html](index.html). It has no tracking or third-party scripts. GitHub Pages can serve it at the URL above.

To publish using the included GitHub Actions workflow: open **Settings → Pages** for this repository and select **GitHub Actions** under **Build and deployment → Source**. The workflow deploys the root `index.html` after changes to `main`, or on manual dispatch. Wait for the `Publish public project site` check to succeed before announcing the public link.

The page is a static showcase, **not** an app capable of controlling real motors or camera streams. Never expose API keys, video feeds or hardware controls on a public static site.

## Safety and engineering honesty

Revision G's approx. $456.70 figure is a priced-parts research estimate, **not** a finished-build cost. Brackets, hardware, wiring, protection and shipping are not fully priced. Before powered use, the design needs independent E-stop, watchdog, obstacle/cliff detection, electrical and mechanical validation.

## Contribution guidance

If proposing a change, reference the source design decision, retain safety boundaries, and distinguish documented plans from physically tested results.
## Interactive lab: actual 3D CAD and virtual controls

- **[3D model viewer](https://matthagersenior.github.io/lilrobbsgirlfriend/viewer.html)**: rotate, zoom, select/highlight every Revision G CAD-derived mesh, transparent shells, assembled/exploded slider.
- **[Exploded assembly](https://matthagersenior.github.io/lilrobbsgirlfriend/viewer.html?mode=exploded)**: all pieces separated visually, with downloadable assembled/exploded GLB files.
- **[Virtual driving simulator](https://matthagersenior.github.io/lilrobbsgirlfriend/simulator.html)**: touch/keyboard differential-drive-style movement, adjustable speed, obstacles, simulated range sensing, basic tap-to-drive waypoint and latched virtual emergency stop.

The 3D exports are generated by `scripts/build_models.py` using **OpenSCAD** from the actual `cad/robot_revG.scad` file (rather than a generic unrelated robot). It exports 24 distinct geometry types, including purchased-component **dimensional proxies**. Two GLBs contain the 32 placed pieces and a ZIP contains the source STL fit-check exports. `scripts/verify_models.py` confirms both GLBs and the site package. Source project CAD is parametric; exports are **not proof of manufacturability, part fit, robot stability or physical safety**.

### Publishing and downloading the models

The `.github/workflows/pages.yml` build job runs automatically for site/CAD changes, verifies source and generated assets, and uploads a `lilrobb-3d-simulator-site` GitHub Actions artifact. This artifact can be downloaded from the completed workflow run **even if Pages is not enabled**; the deployment job needs an additional, one-time Pages setting.

**Required account action:** in repository **Settings → Pages → Build and deployment**, select **GitHub Actions** as source. This cannot be enabled by the default `GITHUB_TOKEN` in the workflow. After enabling Pages, rerun the workflow or push a new change and verify the deployment succeeds before publicly sharing the Pages URL.

Run locally with OpenSCAD, Python 3.11+, `numpy` and `trimesh`:

```sh
python scripts/build_models.py --output _site/models
python scripts/verify_models.py --site _site
```

The simulator is deliberately disconnected from hardware: all motor commands, sensor values, collisions, stopping and battery state are **virtual and approximate**.
